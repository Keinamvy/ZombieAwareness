# Zombie Awareness — Fabric 26.3 Port & Pre-Prod Server Verification Design

## 1. Intent & Motivation
Port **Zombie Awareness** (`com.corosus.zombieawareness`) from Minecraft 1.20.1 (Fabric Loom 1.2 / Java 17) to **Minecraft 26.3 (Fabric)** using Java 25, Fabric Loom 1.17+, Fabric Loader 0.20.1, and Fabric API `0.165.2+26.3`. Verify all ported mechanics through both automated Gradle tests and a real headless Fabric 26.3 server pre-prod test using a separate companion test mod jar so the production mod jar remains 100% free of test harness code.

## 2. Goals, Non-Goals, and Anti-Goals

### Goals
- **Standalone CoroUtil Integration**: Inline and port the required `CoroUtil` classes (`com.corosus.modconfig.*` and `com.corosus.coroutil.util.*` from `libs/coroutil-forge-1.20.1-1.3.6.jar`) directly into `ZombieAwareness` so it runs on Fabric 26.3 without needing an external `coroutil` mod jar.
- **External ForgeConfigAPIPort Dependency**: Update `MobListsConfig` and `ZombieAwarenessFabric` to use `ForgeConfigAPIPort` v26.3.1 (`fuzs.forgeconfigapiport.fabric.api.v5.ConfigRegistry` and NeoForge `ModConfigSpec`), declared as an external dependency (`forgeconfigapiport`) in `fabric.mod.json` rather than bundled via Jar-in-Jar.
- **Default Fabric 26.3 Build**: Make `build.gradle` (and `build_fabric.gradle`) the primary Fabric 26.3 build script using Gradle 9.5+, Fabric Loom 1.17+, and JDK 25 (`C:\Users\Keinamvy\Documents\jdk-25.0.5+8`), excluding Forge-only sources (`com/corosus/zombieawareness/api/forge/**` and `com/corosus/zombieawareness/loader/forge/**`).
- **Minecraft 26.3 API & Mixin Migration**:
  - Update all `ResourceLocation` constructions to `ResourceLocation.fromNamespaceAndPath(...)` / `ResourceLocation.parse(...)` (or 26.3 `Identifier`/`ResourceLocation` API).
  - Update `EntityType.Builder.build(ResourceKey<EntityType<?>>)` registration for `EntityScent`.
  - Update `EntityScent` `SynchedEntityData.Builder` (`defineSynchedData(SynchedEntityData.Builder)`), `kill(ServerLevel)` / `discard()`, and NBT save/load signatures (`ValueInput`/`ValueOutput` or `CompoundTag` in 26.3).
  - Update `AttributeModifier` in `ZAUtil.giveRandomSpeedBoost` to use `ResourceLocation` IDs and `AttributeModifier.Operation.ADD_MULTIPLIED_BASE` instead of `UUID`.
  - Update `RenderScent` (`EntityRenderer<EntityScent, EntityRenderState>`) and vertex building (`VertexConsumer.addVertex(...)`) to match 26.3 client rendering APIs.
  - Update all 15 Fabric mixins (`MixinDedicatedServer`, `MixinEntitySerialization`, `MixinExplosion`, `MixinIntegratedServer`, `MixinLevelEvent`, `MixinLivingEntity`, `MixinMob`, `MixinNoteBlock`, `MixinPlayer`, `MixinPlaySound`, `MixinPreventWandering`, `MixinRecomputePath`, `MixinServerLevel_playSeededSound`, `MixinServerPlayerGameMode`, `MixinTargettingFabric`) to match Minecraft 26.3 method signatures and official mapping names.
- **Automated Unit Tests & Companion Pre-Prod Test Mod**:
  - Write JUnit unit tests for sound profile matching, config parsing, and sense scaling math (`./gradlew test`).
  - Create a separate Gradle sourceSet (`testmod`) and task (`testmodJar`) that builds `zombieawareness-testmod.jar` (`id: "zombieawareness_test"`).
  - Execute a real pre-prod server test in an isolated server directory using `fabric-server-mc.26.3-loader.0.20.1-launcher.1.1.2.jar`, `fabric-api-0.165.2+26.3.jar`, `ForgeConfigAPIPort-v26.3.1-mc26.3.x-Fabric.jar`, the built production `zombieawareness-fabric` jar, and `zombieawareness-testmod.jar`.

### Non-Goals
- Porting the Forge loader entrypoint (`build_forge.gradle` / `loader/forge/**`) to 26.3. Forge files remain untouched and excluded from the Fabric sourceSet.
- Changing gameplay balance or default config values.

### Anti-Goals
- Polluting the main production `zombieawareness-fabric` jar with pre-prod test commands, auto-spawners, or server shutdown hooks.
- Leaving unverified mixins that fail silently at runtime when classes load on the dedicated server.

## 3. Architecture & Technical Decisions

### 3.1 Toolchain & Dependencies (Decided)
- **JDK**: `C:\Users\Keinamvy\Documents\jdk-25.0.5+8` (Java 25, required by Minecraft 26.3 & Fabric API `0.165.2+26.3`).
- **Gradle & Loom**: Gradle 9.5+ wrapper with `net.fabricmc.fabric-loom` `1.17.21` (official Mojang mappings namespace, unobfuscated in 26.3).
- **Compile/Runtime Mods**:
  - `net.fabricmc:fabric-loader:0.20.1`
  - `net.fabricmc.fabric-api:fabric-api:0.165.2+26.3`
  - `ForgeConfigAPIPort-v26.3.1-mc26.3.x-Fabric.jar` (placed in `libs/` for compile/dev, plus its bundled NightConfig `core-3.8.4.jar` & `toml-3.8.4.jar` or Maven dependencies; declared as an external dependency in `fabric.mod.json`, NOT bundled via `include`).

### 3.2 Inlined CoroUtil Subset (Decided)
Only the classes used by `ZombieAwareness` will be extracted from `libs/coroutil-forge-1.20.1-1.3.6.jar` and ported to 26.3 inside `src/main/java/com/corosus/`:
- `com.corosus.modconfig.ConfigComment`
- `com.corosus.modconfig.IConfigCategory`
- `com.corosus.modconfig.CoroConfigRegistry` (lightweight file config reader/writer supporting `@ConfigComment` and static fields in `ZAConfigGeneral`, `ZAConfigClient`, `ZAConfigFeatures`, `ZAConfigPlayerLists`, `ZAConfigMobLists`, `ZAConfigSpawning`)
- `com.corosus.coroutil.util.CU` (`rand()`)
- `com.corosus.coroutil.util.CoroUtilAttributes` (`SPEED_BOOST_ID` ResourceLocation)
- `com.corosus.coroutil.util.CoroUtilBlock` (`blockPos(double, double, double)`)
- `com.corosus.coroutil.util.CoroUtilEntity` (`getName(Entity)`, `canSee(Entity, BlockPos)`)
- `com.corosus.coroutil.util.CoroUtilPath` (`tryMoveToEntityLivingLongDist`, `tryMoveToXYZLongDist`)
- `com.corosus.coroutil.util.CoroUtilWorldTime` (`getDayLength()`)

### 3.3 Companion Test Mod & Real Server Pre-Prod Verification (Decided)
- **Production Jar (`zombieawareness-fabric-<version>.jar`)**: Built from `src/main`, contains zero test harness code.
- **Companion Test Mod Jar (`zombieawareness-testmod-<version>.jar`)**: Built from `src/testmod` via `./gradlew testmodJar`.
  - Registers a server tick listener on `ServerTickEvents.END_SERVER_TICK`.
  - Once the server overworld is loaded, executes an automated multi-stage pre-prod test suite in the live `ServerLevel`:
    1. **Mixin & Registration Check**: Forces classloading/invocation of mixin targets and verifies `ZombieAwareness.SENSE` entity type and custom sound events (`alert`, `target`, `investigate`) are registered in `BuiltInRegistries`.
    2. **Config Generation Check**: Verifies `config/zombieawareness/General.cfg`, `Features.cfg`, `Client.cfg`, `PlayerLists.cfg`, and `MobLists.toml` exist on disk and `MobListsConfig.GENERAL.enhancedMobs.get()` is populated.
    3. **EntityScent Lifecycle & Decay Test**: Spawns an `EntityScent` in the overworld, verifies synched data (`STRENGTH_PEAK`, `AGE`, `TYPE`), ticks it, and confirms age decays as expected.
    4. **Sound & Blood Sense Hook Test**: Triggers `ZAUtil.hookSoundEvent` / `spawnOrBuffSenseAtPos` for both `EnumSenseType.SOUND` and `EnumSenseType.SCENT_BLOOD`, verifying sense node creation and strength buffing on repeated triggers.
    5. **Zombie Spawn Speed Boost & AI Awareness Test**: Spawns a `Zombie` via `finalizeSpawn`, verifies the speed boost attribute modifier is applied, places a nearby `EntityScent`, runs `ZAUtil.tickAI(zombie)`, and verifies the zombie computes a navigation path toward the scent and records `za_last_action`.
  - Writes a clear `PREPROD_TEST_SUMMARY: PASS (5/5)` (or failure details) to the server log and calls `server.halt(false)` to cleanly stop the pre-prod server.

## 4. Builder's Calls (Left to Implementation)
- Exact Minecraft 26.3 method signatures in `ServerLevel`, `Explosion`, `Entity`, `Mob`, `LivingEntity`, and `EntityRenderer` will be verified directly against the decompiled/official 26.3 Minecraft jar in Gradle's cache before editing each class and mixin.
- The pre-prod server instance will be staged in an untracked directory (or cleaned after verification) so large server runtime artifacts (`world/`, `libraries/`, `versions/`) do not bloat git history.
